# Lume Web Companion

Carregue esta pasta como extensão descompactada em Chrome, Edge ou Brave. O Companion diferencia ChatGPT, Claude e Gemini e envia para `127.0.0.1` o agente, título sanitizado, origem, estado, um identificador local da aba e a resposta final exibida. A resposta é usada somente pela sessão local do Lume e não é persistida no histórico.

Quando solicitado pelo usuário, o Companion também ativa a aba correspondente ou entrega um prompt de texto. Imagens, aprovações diretas e interrupção de tarefas continuam na página original.
